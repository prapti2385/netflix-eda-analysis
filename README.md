# Netflix Movies & TV Shows Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies & TV Shows dataset using Python to uncover trends, patterns, and business insights.

## Problem Statement

Streaming platforms generate large volumes of content data. The objective of this project is to analyze Netflix's catalog to identify trends in content type, genres, ratings, release years, countries, and durations through data visualization.

## Dataset

- Source: Kaggle
- Records: 8,800+
- Features: 12

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Business Questions

- How is Netflix's content distributed between Movies and TV Shows?
- Which countries produce the most Netflix content?
- Which content ratings are the most common?
- Which genres dominate Netflix's catalog?
- Which directors have contributed the highest number of titles?
- How has Netflix's content library grown over the years?
- What is the distribution of movie durations?
- Which months witness the highest content additions?

## Key Insights

- Movies dominate Netflix's catalog.
- The United States contributes the highest number of titles.
- TV-MA and TV-14 are the most common ratings.
- International Movies and Dramas are the leading genres.
- Most movies have durations between 80–120 minutes.
- Netflix experienced rapid content growth during the late 2010s.
