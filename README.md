# Netflix Movies & TV Shows Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to uncover trends, patterns, and business insights using Python.

## Objectives

- Perform data cleaning and preprocessing
- Analyze content distribution
- Explore release year trends
- Analyze genres and ratings
- Visualize insights using charts

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
